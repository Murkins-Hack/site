# MURK1INSHOPSPORTFOLIO

Интерактивный киберпанк / брутализм витринный интернет-магазин брендовой одежды и кроссовок (Balenciaga, Vetements, Stone Island).

## Особенности
- **3D 360° интерактивный просмотр** товаров
- **Феррофлюидные шейдерные эффекты** и частицы
- **Аудио-сопровождение** и эффект дешифровки текста (Hacker/Decrypted Text)
- **Каталог товаров** с фильтрацией, детальными карточками и корзиной
- **Быстрая раздача в сеть** через Cloudflare Tunnel (`РАЗДАТЬ_САЙТ.bat`)

## Запуск
- Открыть `index.html` в браузере или запустить `npm run dev` для React-версии.
- Для публикации ссылки в интернет: запустить `РАЗДАТЬ_САЙТ.bat`.
